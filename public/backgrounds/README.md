# Tła formularzy rekrutacyjnych SKN

Umieść w tym katalogu opcjonalne obrazy tła w formacie `.webp` (zalecane 1920×1080, lekkie skompresowane):

- `skn_seksuologii.webp` — SKN Seksuologii
- `uzaleznienia.webp` — SKN Zachowań Ryzykowych i Uzależnień
- `psychoonkologia.webp` — SKN Psychoonkologii
- `skn_dzieci_i_mlodziezy.webp` — SKN Psychologii Dzieci i Młodzieży (SKN PDiM)

Jeśli plik dla danego koła nie istnieje lub nie załaduje się poprawnie, formularz rekrutacyjny automatycznie używa domyślnego gradientu CSS koła jako bezpiecznego fallbacku.
